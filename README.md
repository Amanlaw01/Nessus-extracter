## Overview

**EaseNessus** is a Python-based tool that simplifies the analysis of **Nessus (`.nessus`) vulnerability scan reports**.

Instead of manually reviewing hundreds or thousands of findings, EaseNessus consolidates duplicate vulnerabilities, merges affected hosts and ports, and generates a cleaner, more organized output for reporting.

Whether you're performing a penetration test, vulnerability assessment, or security audit, EaseNessus helps reduce repetitive work, improve reporting efficiency, and save valuable time.

---

## Installation

### Clone the repository

```bash
git clone https://github.com/aman-ghale/EaseNessus.git
```

### Navigate to the project directory

```bash
cd EaseNessus
```

### Run the application

**Windows**

```bash
python easenessus.py
```

**Linux**

```bash
python3 easenessus.py
```
